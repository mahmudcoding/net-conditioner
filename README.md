# Net Conditioner

**[English version → README.en.md](README.en.md)**

Приложение в строке меню macOS, которое ограничивает скорость интернета,
добавляет задержку и теряет пакеты — чтобы посмотреть, как любое приложение
или сайт ведёт себя на плохой сети. Один клик — включили профиль «EDGE»,
один клик — выключили.

В отличие от троттлинга в DevTools браузера, шейпинг работает на уровне
системы: он затрагивает **все** программы и **все** протоколы, включая UDP —
то есть видеозвонки, VoIP и игры, а не только загрузку страниц.

## Установка

1. Скачайте `Net-Conditioner-x.y.z-macOS-arm64.zip` со страницы
   [Releases](https://github.com/mahmudcoding/net-conditioner/releases).
2. Распакуйте и перетащите `Net Conditioner.app` в «Программы».
3. При первом запуске: правый клик → «Открыть» (приложение подписано
   ad-hoc, поэтому macOS один раз переспросит).
4. В строке меню появится спидометр.

Требования: macOS 13+, Apple Silicon. Обновления приложение получает само
(Sparkle): «Check for Updates…» в меню или автоматическая проверка раз в день.

## Использование

Клик по спидометру → выбираете профиль → вводите пароль администратора
(его запрашивает системный диалог macOS, приложение пароль не видит).
Пока шейпинг активен, иконка превращается в черепаху. «Turn Off»
возвращает нормальную сеть. «Custom…» — свои цифры, «Check Connection…» —
измеряет фактические скорость, задержку и потери.

| Профиль | Вниз | Вверх | RTT | Потери |
|---|---|---|---|---|
| EDGE | 240 kbit | 200 kbit | 400 мс | — |
| 3G | 780 kbit | 330 kbit | 100 мс | — |
| LTE | 50 Mbit | 10 Mbit | 50 мс | — |
| DSL | 2 Mbit | 256 kbit | 5 мс | — |
| Very Bad | 1 Mbit | 1 Mbit | 500 мс | 10% в обе стороны |
| Packet Loss 8% | — | — | — | 8% на отправку |
| Packet Loss 15% | — | — | — | 15% на отправку |
| Blackout | — | — | — | 100% в обе стороны |

## Из терминала

Всё то же самое умеет скрипт `netcond` из репозитория:

```bash
./netcond preset 3g
./netcond set --down 1mbit --up 256kbit --rtt 300 --loss 5
./netcond set --loss-up 8 --host example.com
./netcond status
./netcond verify
./netcond off
```

`--host` ограничивает шейпинг трафиком к конкретным хостам (по умолчанию —
вся машина). `--dry-run` печатает команды, ничего не меняя. Повторное
применение заменяет активный профиль, ничего не накапливается.

## Как это устроено

Шейпинг делают штатные механизмы macOS: пайпы dummynet (`dnctl`) плюс
pf-якорь `netcond` (`pfctl`). Всё живёт только в памяти ядра:

- `/etc/pf.conf` на диске никогда не изменяется;
- выключение удаляет только свои пайпы (9101/9102), свой якорь и свою
  pf-ссылку — чужие правила не трогаются;
- перезагрузка Mac гарантированно возвращает всё как было.

## Важно

- Без `--host` замедляется **вся машина** — включая ваш браузер, мессенджеры
  и фоновые синхронизации. Не забывайте «Turn Off».
- Не включайте одновременно Network Link Conditioner от Apple — два шейпера
  будут мешать друг другу (`netcond status` предупреждает о чужих пайпах).
- Локальный трафик (localhost) не замедляется никогда.

## Удаление

«Turn Off», затем удалите приложение из «Программ» и `rm -rf ~/.netcond`.
